# Kalkulator Bleach ⚔️

Kalkulator bertema anime Bleach, dibuat pakai HTML, CSS, dan JavaScript.

🔗 **Coba di sini:** https://muqorobin298-lab.github.io/Kalkulator-bleach-/

## Fitur
- Tambah, kurang, kali, bagi, dan sisa bagi (%)
- Bisa dipakai lewat tombol atau keyboard
- Tombol AC (hapus semua) dan DEL (hapus satu digit)
- Latar anime berganti tema setiap hitungan selesai, sampai BANKAI!
- Pesan error kalau dibagi nol
